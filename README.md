# inventory-monitoring-system
A local inventory management prototype built with PHP and MariaDB. It supports role-based access, product catalog management, and read-only inventory balances.

# Inventory Monitoring and Stock Management System

This project provides a local web application for managing a product catalog and monitoring inventory quantities. It uses PHP, MariaDB, and Apache, with setup scripts for 64-bit Windows.

## Current milestone

- Four user roles with access based on assigned responsibilities
- Product creation, editing, archiving, and reactivation
- Inventory views showing on-hand, reserved, and available quantities
- Repeatable database setup and documented verification checks

Stock receipts, orders, sales, returns, and reporting are planned for later milestones.
